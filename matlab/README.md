# MATLAB 复核与外部依据

## 公式推导与正确性说明

完整推导见 [数学模型推导与程序正确性验证](../docs/model-derivation.md)，可编辑 Word 文件为 [数学模型推导与程序正确性验证说明.docx](../docs/数学模型推导与程序正确性验证说明.docx)。其中包含 35 个公式、TKE 与风三角推导、旋翼质量与速度功率的依据、单位换算、A* 一致性证明、换电账本及经验参数边界，并列出代码和 MATLAB 的覆盖范围。

新增 `verify_analytic_cases.m` 用可手算的闭式答案核对网页：七个固定风况、均匀 TKE 最短路、无风 6 km 耗电、悬停耗电及模型内速度极小值。`run_validation` 会同时执行它；输入随 `npm run matlab:fixtures` 导出。结果在 `analytic_verification_report.txt` 和两个 `analytic_*_verified.csv` 中。独立手算答案减少两套实现重复同一错误的风险，但不替代机型实测标定。

## 一键复核

本机已用 MATLAB R2024b 实际运行，下列检查全部通过。先在仓库根目录生成同一批输入，再让 MATLAB **独立重算**：

```powershell
npm run experiment
npm run matlab:fixtures
matlab -batch "addpath('matlab'); run_validation;"
```

本次输入文件已经导出，你可以直接在 MATLAB 中把“当前文件夹”切换到仓库根目录（能看到 `index.html` 和 `matlab` 文件夹），再在命令窗口输入。后续修改网页算法时，先执行上面的导出命令，再重新复核：

```matlab
addpath('matlab');
run_validation;
```

脚本已在本机 **MATLAB R2024b** 实际运行，无需 Simulink。检查通过后才生成图；任何 `assert` 失败都会停止，必须先查明差异。只检查数值可运行 `verify_demo;`。日志在 `matlab/verification_report.txt`，图片在 `matlab/figures/`，独立重算值在 `*_verified.csv`。`npm run experiment` 会重新生成三组固定种子的 JavaScript 基准值；不要手工修改 `matlab/fixtures` 中的数据。

## 怎样用六张图说明设计正确性

先明确三项验收问题：**搜索是否得到同一离散图上的最优代价；时间与耗电是否按所定公式正确累计；换电和阵风等待的状态是否符合设计规则。**图是展示证据的方式，断言与数据文件才负责判断通过或失败。

| 图片（`matlab/figures/`） | MATLAB 做了什么 | 汇报时可以说什么 |
|---|---|---|
| `01_route_search.png` 航路与搜索代价 | 对网页导出的相同安全有向边独立运行 Dijkstra，与 D 题代价 A* 对比三个种子 | 三组输入中，D 题代价 A* 与独立最优代价在舍入容差内一致。左图的演示综合路线仅展示权衡，没有证明综合任务在连续空间全局最优。 |
| `02_time_energy_agreement.png` 时间与耗电复核 | 根据 307 个航段的风矢量、距离、TKE 独立计算地速、功率、秒数和 Wh | 九条路线的时间与能量差均低于 0.005001；基准值保留两位小数，这一容差对应舍入误差。 |
| `03_speed_payload_energy.png` 速度、载荷与 TKE | 独立重算 96 个组合，逐项与网页公式比较 | 在当前教学功率模型中，提高载荷和 TKE 会增加耗电；提高速度减少用时，但单位里程耗电存在取舍。不能说曲线已经得到真实无人机标定。 |
| `04_battery_swap_timeline.png` 换电电量与时间 | 核对 1,031 个软件回放采样点的时间账本、保留电量、换电补入电量与到达时间 | 默认任务换电一次，电量恢复 220 Wh；总用时为 909.35 + 120 = 1029.35 秒。无站点时无满足电量约束的方案。 |
| `05_gust_wait_energy.png` 阵风等待 | 用每秒记录的当前位置风、TKE、阵风幅值独立积分悬停功率；检查位置与恢复状态 | 本例大范围阵风阻断前方航路，当前位置安全，等待 240 秒位移为 0，但耗电 66.81 Wh；阵风结束后恢复飞行。保护停演本身冻结演示，只有进入等待才计时耗电。 |
| `06_wind_safety_cases.png` 风况允许与拒绝 | 独立分解迎风与侧风，检查地速和教学风速上限 | 六个局部算例的判断一致：过强逆风、不可补偿的侧风或超过风速限会拒绝前进。实际限值仍需具体机型依据。 |

每张图同时输出 **PNG**（插入 PPT）、**PDF**（缩放查看与打印）和 **FIG**（MATLAB 可编辑）。`MATLAB_validation_all.pdf` 包含全部六页。查看可编辑图可用 `openfig(fullfile('matlab','figures','03_speed_payload_energy.fig'),'new','visible');`；更改程序后应重新导出并运行验证，不能只改图上的文字或数值。

当前验证固定使用 61×41 网格、200 m 间距、12 m/s 巡航空速、1 kg 载荷、650 W 基础功率；默认换电回放使用 220 Wh 电池、95% 初始电量、20% 保留量和 120 秒换电。修改这些模型参数时，也要同步 MATLAB 参考参数与实验定义，保留代码差异和重新运行的日志。三个种子和六个风况算例是有限测试，不是对所有可能场景的数学证明。

MATLAB 使用 [MathWorks `digraph` 与 `shortestpath` 官方文档](https://www.mathworks.com/help/matlab/ref/graph.shortestpath.html)中的正权 Dijkstra，与网页 A* **比较总代价，而不强求完全相同的等价路径**。由于逆风/顺风使可飞行性可能有方向差别，导出的是有向边。其余检查不用调用网页的 JavaScript 公式：

| 检查 | MATLAB 独立计算 | 本次结果 | 能证明什么 |
|---|---|---|---|
| 路径代价 | 逐边计算 `d × [1 + 200 × ((TKE_a+TKE_b)/2)^1.5]`，对相同安全边集运行 Dijkstra | 三个种子均与网页 A* 代价一致 | 给定同一网格和安全边，A* 搜索目标实现正确 |
| 航段物理量 | 分解顺风/侧风，重算地速、功率、时间和 Wh | 九条路线的距离、TKE 暴露、时间、Wh、论文代价均一致 | 算式和单位换算在两套实现中一致 |
| 换电 | 用计划飞行秒数加固定换电秒数 | `909.35 + 120 = 1029.35 s`，即约 17:09；无站点方案不可行 | 该固定任务的计时与可行性状态一致 |
| 局部风况判定 | 独立计算迎风、侧风、地速与教学风限 | 6 个普通风/强逆风/强侧风等案例一致 | 局部航段的可飞行判定实现一致 |
| 参数方向 | 比较速度和载荷的单位里程能耗 | 12 m/s 低于 6 与 18 m/s；载荷增加时功率上升 | 教学功率函数满足所设定的趋势 |
| 参数组合 | 对 96 组速度、载荷和 TKE 组合独立重算功率与 Wh/km | 与网页逐项一致 | 公式在这组参数范围内实现一致 |
| 换电回放 | 核对 1,031 个采样点的时间和电量账本、换电补入量及保留电量 | 默认任务全程通过 | 当前默认任务的执行记录满足设计恒等式 |
| 阵风等待 | 对 240 秒逐秒输入独立积分悬停功率，核对位置与恢复状态 | 位移 0，耗电 66.808011 Wh，结束后恢复飞行 | 该固定等待案例的扣电与计时实现一致 |

这里导出的 **安全边、气象输入和系数仍来自网页的合成模型**。MATLAB 验证的是独立程序对同一模型的数值复核，不验证萧山真实 300 m 风场、机型的功率曲线，或“14 m/s 禁飞、120 s 换电”等教学参数。特别是 MATLAB 无法凭导入的安全边集检验网页是否遗漏了真实禁飞空域或障碍物。MATLAB 现已独立核对一个固定大范围阵风案例的等待能量积分、位置与恢复状态；随机天气生成、多处阵风叠加和其他状态转移仍由 `npm test` 的 JavaScript 用例覆盖。完整的跨语言动态规划复现还需要 MATLAB 自行实现天气生成、安全边更新和重规划状态机。

## 要进一步证明“接近真实”的实验

1. 获取有来源和时间戳的同一高度风速/风向、三分量脉动观测；对齐投影、空间位置、采样窗口与时区。按 `TKE = 0.5 × [var(u') + var(v') + var(w')]` 求观测 TKE，并报告风速 MAE、TKE RMSE、强阵风检出/漏检，而不是仅与合成“真值”比较。
2. 选定具体无人机型号，记录厂家核准的风速、载荷、电池与返航限制，实测不同速度、载荷、迎风/顺风情况下的电压、电流和实际飞行时间；积分 `Wh = ∫V(t)I(t)dt / 3600` 标定功率函数。测试日与标定日分开。
3. 使用真实地图的建筑物、禁飞区、起降点和换电设施；重复任务并记录计划/实际轨迹、重规划响应、任务完成率、电量裕度、总用时误差。真实飞行需要依法办理相应运行手续和安全评估，不能按本网页的教学阈值直接起飞。
