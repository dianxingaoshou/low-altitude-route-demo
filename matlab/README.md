# MATLAB 复核与外部依据

## 一键复核

本机已用 MATLAB R2024b 实际运行，下列检查全部通过。先在仓库根目录生成同一批输入，再让 MATLAB **独立重算**：

```powershell
npm run experiment
npm run matlab:fixtures
matlab -batch "addpath('matlab'); verify_demo"
```

也可在 MATLAB 命令窗口打开仓库目录，运行 `addpath('matlab'); verify_demo`。输出保存在 `matlab/verification_report.txt`。`npm run experiment` 会重新生成三组固定种子的 JavaScript 基准值；不要手工修改 `matlab/fixtures` 中的数据。

MATLAB 使用 [MathWorks `digraph` 与 `shortestpath` 官方文档](https://www.mathworks.com/help/matlab/ref/graph.shortestpath.html)中的正权 Dijkstra，与网页 A* **比较总代价，而不强求完全相同的等价路径**。由于逆风/顺风使可飞行性可能有方向差别，导出的是有向边。其余检查不用调用网页的 JavaScript 公式：

| 检查 | MATLAB 独立计算 | 本次结果 | 能证明什么 |
|---|---|---|---|
| 路径代价 | 逐边计算 `d × [1 + 200 × ((TKE_a+TKE_b)/2)^1.5]`，对相同安全边集运行 Dijkstra | 三个种子均与网页 A* 代价一致 | 给定同一网格和安全边，A* 搜索目标实现正确 |
| 航段物理量 | 分解顺风/侧风，重算地速、功率、时间和 Wh | 九条路线的距离、TKE 暴露、时间、Wh、论文代价均一致 | 算式和单位换算在两套实现中一致 |
| 换电 | 用计划飞行秒数加固定换电秒数 | `909.35 + 120 = 1029.35 s`，即约 17:09；无站点方案不可行 | 该固定任务的计时与可行性状态一致 |
| 局部风况判定 | 独立计算迎风、侧风、地速与教学风限 | 6 个普通风/强逆风/强侧风等案例一致 | 局部航段的可飞行判定实现一致 |
| 参数方向 | 比较速度和载荷的单位里程能耗 | 12 m/s 低于 6 与 18 m/s；载荷增加时功率上升 | 教学功率函数满足所设定的趋势 |

这里导出的 **安全边、气象输入和系数仍来自网页的合成模型**。MATLAB 验证的是独立程序对同一模型的数值复核，不验证萧山真实 300 m 风场、机型的功率曲线，或“14 m/s 禁飞、120 s 换电”等教学参数。特别是 MATLAB 无法凭导入的安全边集检验网页是否遗漏了真实禁飞空域或障碍物。动态阵风的生成、多处叠加和等待状态机目前由 `npm test` 中的 JavaScript 用例覆盖；若要跨语言复核全过程，应再导出每秒位置、风速、状态和电量时间序列，由 MATLAB 比较轨迹偏差与重规划时刻。

## 要进一步证明“接近真实”的实验

1. 获取有来源和时间戳的同一高度风速/风向、三分量脉动观测；对齐投影、空间位置、采样窗口与时区。按 `TKE = 0.5 × [var(u') + var(v') + var(w')]` 求观测 TKE，并报告风速 MAE、TKE RMSE、强阵风检出/漏检，而不是仅与合成“真值”比较。
2. 选定具体无人机型号，记录厂家核准的风速、载荷、电池与返航限制，实测不同速度、载荷、迎风/顺风情况下的电压、电流和实际飞行时间；积分 `Wh = ∫V(t)I(t)dt / 3600` 标定功率函数。测试日与标定日分开。
3. 使用真实地图的建筑物、禁飞区、起降点和换电设施；重复任务并记录计划/实际轨迹、重规划响应、任务完成率、电量裕度、总用时误差。真实飞行需要依法办理相应运行手续和安全评估，不能按本网页的教学阈值直接起飞。
